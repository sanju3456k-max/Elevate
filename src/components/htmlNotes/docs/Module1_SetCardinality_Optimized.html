Deep Dive: Module 1 — Set Cardinality & Countability

1. Mathematical Definitions & Fundamental Concepts

Term / Concept Precise Definition & Conditions Key Properties / Mathematical Notation
Countable Set A set \(S\) is defined as countable if it satisfies one of three conditions:
1. \(S = \emptyset\) (Empty set).
2. \(S\) is a finite set.
3. \(S\) is a countably infinite set.		 Covers both finite and countably infinite sets.
Countably Infinite (Denumerable) Set An infinite set \(S\) is countably infinite if it is in a one-to-one correspondence (bijective equivalence) with the set of natural numbers \(\mathbb{N}\). Written as \(S \sim \mathbb{N}\)
• Cardinality: \(|S| = |\mathbb{N}| = \aleph_0\) (Aleph-null)
Uncountable Set A set \(S\) is uncountable if it is not countable. • Cardinality Condition: \(|S| > \aleph_0\)
• Denoted as continuum cardinality \(c = 2^{\aleph_0}\)
Cardinal Equivalence Two sets \(A\) and \(B\) have the same cardinality if and only if there exists a bijective function between them. \(|A| = |B| \iff \exists f: A \to B\) that is both \(1-1\) (injective) and onto (surjective).
Algebraic & Transcendental • Algebraic Number: Any real or complex number that is the root of a non-zero polynomial with rational coefficients.
• Transcendental Number: Any real number that is not algebraic.		 Classification of real/complex numbers based on polynomial roots.

2. Injective & Surjective Mapping Principles

Theorem / Principle Core Definition & Mapping Condition Implications, Results & Mastery Points
Theorem (Injective Bound) Let \(A\) and \(B\) be sets, and let \(f: A \to B\) be a \(1-1\) (injective) function. • Implication: \(|A| \le |B|\).
• Result 1: If \(B\) is countable, then \(A\) MUST be countable.
• Result 2: If \(A\) is uncountable, then \(B\) MUST be uncountable.
• Mastery Point (Converse Failure): If \(A\) is countable, \(B\) is not guaranteed to be countable; if \(B\) is uncountable, \(A\) is not guaranteed to be uncountable.
Theorem (Surjective Bound) Let \(f: A \to B\) be an onto (surjective) function. • Implication: If \(A\) is countable, then \(B\) MUST be countable.

4. Fundamental Theorems & Structural Algebra

Structural Category Theorem / Principle Mathematical Formulations & Examples
A. Subset & Superset Theorems • Theorem (Subset Rule): Every subset of a countable set is countable.
• Theorem (Superset Rule): Every superset of an uncountable set is uncountable.		 Relates cardinality bounds between sets and their subsets/supersets.
B. Union & Difference Theorems • Theorem (Countable Union): Countable union of countable sets is countable.
• Theorem (Union with Uncountable): Countable \(\cup\) Uncountable is uncountable.
• Theorem (Set Difference): Uncountable \(\setminus\) Countable is uncountable.		 Example: \(\mathbb{R} \setminus \mathbb{Q} = \mathbb{Q}^c\) (Irrational numbers are uncountable).
C. Product Theorems • Cartesian product of two countable sets is countable.
• Infinite Cartesian product of non-singleton finite sets is uncountable.		 Expressed notationally as \(\prod_{i=1}^\infty A_i\).

5. Function Spaces & Power Sets

  • Function Set Cardinality: For $S = \{f \mid f: A \to B\}$, total functions = $|B|^{|A|}$.
    • $f: \mathbb{N} \to \{0,1\}$ has cardinality $2^{\aleph_0} = c$ (Uncountable).
    • $f: \{0,1\} \to \mathbb{N}$ has cardinality $\aleph_0^2 = \aleph_0$ (Countably Infinite).
  • Power Set Theorems: $P(\emptyset)$ is finite, $P(\mathbb{N})$ is uncountable. No set has a power set of cardinality $\aleph_0$. Finite subsets of $\mathbb{N}$ are countable, while arbitrary subsets ($P(\mathbb{N})$) are uncountable.

6. Exam Recognition Patterns & Shortcut Tricks

  • Recognition Pattern 1 (\(\mathbb{R}^n\) Algebraic Constraints): Sets defined by linear constraints in rational coordinates are subsets of $\mathbb{Q}^n$ (countable); continuous real equations in $\mathbb{R}^2$ or $\mathbb{R}^n$ form continuum lines (uncountable).
  • Recognition Pattern 2 (Recurring Decimals vs Irrational Constants): Recurring decimals form subsets of $\mathbb{Q}$ (countable). Primes mapping $\mathbb{P} \times \mathbb{P}$ form countable sets.
